# IVER — Project Foundation

## 1. Problem Statement
    The internet contains a large amount of information, but verifying whether a claim is factually supported by reliable evidence can be difficult and time-consuming.

    IVER aims to be an AI-powered research and claim-verification system that accepts research questions or claims, retrieves relevant evidence from available sources, evaluates the relationship between claims and evidence, and presents explainable results with supporting references.

    The system will combine information retrieval, natural language processing, machine learning, backend services, and a user-facing interface to make evidence-based research more efficient and transparent.

    The system must distinguish between claims supported by evidence, claims contradicted by evidence, and claims for which the available evidence is insufficient. It must not treat a model prediction as proof of factual correctness.
